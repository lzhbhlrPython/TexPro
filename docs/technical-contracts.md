# 技术契约

本文记录改功能时必须维持的数据和生命周期关系；模块介绍见 [架构](architecture.md)，执行命令见 [开发指南](development.md)。

## 文档、工程与主文件

磁盘 `.tex` 是原件，CodeMirror 文档是未保存内容的编辑状态，可视 decoration 只是投影。打开文件、工程根目录、编译主文件是三个不同身份。

主文件由 `project-root.cjs` 共用解析：显式 `.texpro/project.json.rootFile` 优先，否则仅接受唯一未注释的 `\documentclass` 候选。歧义、配置失效和路径越界需要明确处理，不以当前标签页静默替代。保存、编译、依赖安装、导出、SyncTeX 和 MCP 共用该入口。

## 保存与文件操作

`saveQueue.ts` 串行写入，成功只确认该次提交的快照；期间继续输入的内容仍为脏状态。编译前保存全部相关缓冲区，随后重读磁盘工程配置。

移动或改名通过 `project-operations.cjs` 准备路径引用修改；前端 `fileOperations.ts` 把结果映射到打开缓冲区，保留等待期间的新输入和编辑会话。失败回滚已执行的文件操作；此保证不包括断电或进程崩溃。

素材库和文件树共享文件系统。删除要维护索引、打开文件与引用提示，不能只删一侧列表。编辑器撤销和素材磁盘操作不是同一持久事务，不能声称所有外部文件变动都可由 Ctrl+Z 恢复。

## 异步身份与写作目标

任何异步回写都核对工程代数、文件身份、请求序号或 runId。取消请求只是节省工作，不能替代接收端的过期结果检查。

`writingTargets` 记录源范围与原文，周边编辑映射位置，目标原文发生变化则失效。工具确认、AI 回写和跨文件依赖插入不能仅拿旧 offset 写入。IME 组合期间保留正在编辑的投影；不要重建全文来换预览。

## 预览与 PDF

KaTeX 处理支持的数学内容；复杂 TeX 由本机工具链编译，失败保留源码和诊断。图示预览复用主文件导言区，乐谱使用自己的最小文档与独立构建目录；预览取消不能误停主编译。成功结果才进入缓存。

PDF.js 负责显示及 viewport 变换，SyncTeX 提供文字锚点与排版盒子。点击、框选、滚动定位需在同一坐标系处理缩放、裁切和旋转。框选是映射推断的行范围，跨文件只打开匹配最多的文件并提示，不宣称字符级精确映射。

实时 TeX 预览是 L0 内部增强，遵守原有自动编译策略、主文件与引擎判定，在同一个 PdfPane 内使用独立 worker 与 rtex-ts 会话，不新增开关或预览模式。未保存缓冲区只进入快照，IME 组合结束后同步；会话 ID 和源码版本隔离旧结果。段落覆盖与完整布局按版本合并，无法准确绘制的页面回退匹配 PDF。实时画面不复用正式 PDF 的旧文本层或 SyncTeX；PDF 专业操作按需准备与当前源文匹配的正式结果，手动编译、导出仍走原有保存与构建流程；输入后恢复内部实时绘制。生命周期、资源上限、ASAR 分发和 MIT 来源见 [实时预览契约](realtime-tex.md)。

## 关闭、退出与恢复

保存失败保留工程和窗口；保存成功再取消编译、清理会话并关闭。macOS 普通关窗与退出应用分开处理。`quit-watchdog.cjs` 只在不可取消 quit 后武装，属于原生收尾兜底，不能用于绕过保存。

工程重开恢复文件、选择和滚动，不跨进程恢复完整撤销栈。未完成备忘与占位符仍保存在源码，不能依赖某个 UI 面板活着才存在。

## IPC、MCP 与打包

主进程处理文件和命令，preload 提供白名单包装，`src/api.ts` 定义接口，`src/types.ts` 定义共享数据。保持 contextIsolation 和 Node 隔离；当前 sandbox 设置不能被描述为完整沙箱保证。校验真实路径、参数、sender 与异步生命周期。

MCP 是普通 Node stdio 进程，只读到磁盘；stdout 只输出协议。写作修改验证最新文件哈希与主文件哈希。新增被外部 Node 使用的服务，检查 `asarUnpack`、发布资源清单和真实包外启动；开发环境 require 成功不是打包验收。

## 发布契约

Nightly 根据上海当天 first-parent 提交的实际文件差异判断是否构建；空提交不计。日期只算一次，版本 `v{基础版本}-YYYYMMDD-Nightly`，包内省略 v，生成版本不提交回仓库。三平台成功才发布；成功后 dispatch Pages 并传准确 tag。Pages 指定 tag 同步失败必须失败，普通离线构建才允许旧快照。

官网仅产品页路径变化或成功 Nightly 刷新自动重建；PR 只验证，main 才部署。详见 [部署说明](product-page-deployment.md)。

## 插件包与主题

API 1 使用本地 ZIP／目录快照、禁用安装、显式启用、版本回退与受信任 Node 子进程。SDK 不传输内部 UI 对象；正文回写校验工程、文件、文档身份和包摘要，通过单次事务保留撤销。主题预览与应用共用主题提供器，清理所有包 token／CSS／字体。代码与主题都需要来源信任，进程与 CSS 作用域不是安全沙箱。原生视图重置与 `--safe-mode` 可停用所有包。详细路径、大小、能力和实验性接入边界见 [插件与主题开发](extension-development.md)。
