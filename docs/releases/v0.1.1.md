# TeXPro v0.1.1 · Tajpilo

## 中文

- 官网语言通过声明文件接入，词典与文档自动发现；缺译明确回退，构建校验语义键及插值变量。
- 官网首页分别展示正式版与 Nightly 构建，链接真实 Release。
- Nightly 增加小时级补偿检查，延迟执行按最近一次上海时间 21:23 窗口归属日期，避免跨午夜误标；同窗口已发布时跳过自动重复构建。

安装包仍未签名、公证；本地 TeX 工具链要求不变。GitHub 调度不保证准点，补偿机制不能替代外部调度 SLA。三平台构建和包内核验由发布工作流执行，打包成功不等于所有系统安装运行验收。

## English

- Website languages use declarative metadata, automatically discovered catalogues and articles, explicit translation fallback, and build-time key/placeholder validation.
- The homepage presents stable and Nightly releases separately.
- Hourly recovery checks compensate for delayed schedules. Nightly dates follow the most recent 21:23 Asia/Shanghai window, and scheduled checks skip a window with an already published build.

Installers remain unsigned and unnotarized; local TeX requirements are unchanged. GitHub scheduling is not punctual by guarantee. The release workflow performs three-platform packaging and package verification; packaging is not installation/runtime acceptance on every system.
