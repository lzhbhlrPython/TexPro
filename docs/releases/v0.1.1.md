# TeXPro v0.1.1 · Tajpilo

2026-11-14 · 相对 v0.1.0 的完整更新 / Changes since v0.1.0

## 中文

本次更新重点是桌面语言插件、扩展分发与构建流程，以及官网多语言和文档体验；不仅包含最后一轮 Nightly 与首页调整。

### 重大修复重发（2026-11-14）

- 替换早先的 v0.1.1 构建：移除“更多”菜单中与工作台重复的插入组；保留命令面板及快捷键插入能力。
- 修复视图模式、专注模式、打字机滚动的动态标签及六种图示插入命令的语言键，避免简中界面混入英文。
- 正式发布后 Nightly 使用下一补丁版本；首页在原下载列表内切换正式版／Nightly，系统包与 Skill 共用下载行，Skill 大小显示 KB。
- 更新开发 Skill 的版本参考、动态文案、多语言发现与发行集成约束。此次同版本替换由维护者明确授权，保留完整测试及三平台打包闸门；旧二进制不再作为当前下载。

### 桌面语言与国际化

- 简体中文拆为随应用预装的声明式语言插件，英文保留为内置恢复语言；偏好设置与原生菜单共用受检语言资源。
- 短文案迁移到稳定语义键和独立 JSON，宿主与 SDK 共用英文源目录，区分可翻译标签、技术标识与作者数据，避免改写正文、文件名或插件返回值。
- 支持语言包启停、卸载、缺译回退和异步刷新隔离；英文资源加载失败提供独立的最小恢复界面，原生恢复命令始终使用内置英文。
- **语言包契约升级为 `catalogVersion: 2`，扩展 `apiVersion` 仍为 1。旧正文键语言包会被明确拒绝，需要按新参考目录迁移译文、校验变量并重新打包；仅修改版本字段无效。**

### 扩展安装、分发与开发

- 增加 npm／yarn 专用扩展环境，通过 qwertysay 同步新增、更新与卸载，并在 TeXPro 逐项审核；安装后保持停用，卸载默认保留插件数据，环境所有权避免接管手动安装或其他环境的扩展。
- 保留 `texpro.package` 指向 `.tpp`／`.tpt` 的分发方式，同时支持 `texpro.source` 源码包。自包含 JavaScript、语言 JSON、静态片段和主题可校验后同步，不在原始 node_modules 中直接执行。
- 需要编译的源码包须显式选择构建：核对包身份与风险后复制源码、安装编译依赖并调用工具链。依赖生命周期脚本默认禁用；信任安装脚本是单独、默认拒绝的选择。构建产物绑定源码摘要，失败或源码变化时拒绝旧产物。
- 功能插件维护独立语言资源，每次调用取得当前语言。语言包模板、构建引导与共享校验同步更新；仓库配套版本为 SDK 0.5.0、qwertysay 0.6.0、预制简中包 2.0.0，独立 npm 包的发布状态与应用版本分开管理。
- MCP 格式查询及包检查复用公共校验，支持语言包新契约与 npm 源码状态说明；检查保持只读，不安装、构建或执行插件。
- 正式版与 Nightly 新增版本化扩展开发 `.skill` 资产，包含完整说明和引用资源，并与受测源码核对。

### 官网与文档

- 官网新增世界语界面、文档及长篇内容资源，提供统一语言菜单；新增语言改为提交声明 JSON、消息 JSON 与 Markdown，无需修改页面或路由。缺译明确回退，构建检查语义键与插值变量。
- 使用文档 `/docs` 与开发文档 `/developers` 直接进入实际文章，共用阅读器、目录、搜索与前后篇导航；原有 `/docs/:slug` 链接保持稳定。代码块增加按需语法高亮。
- 首页原下载列表内切换正式版与 Nightly，链接真实公开 Release；正式版本浏览按版本系列整理。新增英文根 README，并补齐扩展安装、语言包与翻译贡献说明。

### 发布与验证

- Nightly 保留上海时间 21:23 入口，增加小时级补偿检查；延迟执行归属最近一次 21:23 窗口，避免跨午夜误标，同窗口已有公开构建时跳过自动重复发布。手动同日重建保留。
- 正式发布补齐草稿 Release 查询与资产完整性处理，保留失败重试身份及发布后官网刷新。
- 本次替换源码已通过完整回归（162 项、零失败／跳过／TODO）、类型与构建；官网构建及文档检查通过。远端三平台打包和最终公开状态以此次 Actions 结果为准。
- 原 v0.1.1 已通过完整回归（159 项、零失败／跳过／TODO）、类型与构建检查、三平台打包及发行包核验，交付 8 个安装包和开发 Skill。另验证官网语言切换、第四语言文件发现、文档分区及宽窄屏布局。

安装包仍未签名、公证；本地 TeX 工具链要求不变。构建、安装和启用扩展分别需要判断可信来源，临时目录不是沙箱。GitHub 调度不保证准点；三平台打包不等于所有系统的安装运行验收。世界语中本轮新增的 6 个界面键暂回退英文，待翻译贡献者补齐。

## English

This release covers all changes since v0.1.0, including desktop language plugins, extension distribution and source builds, and the multilingual website.

### Critical-fix replacement (2026-11-14)

- Replaces the earlier v0.1.1 build: removes the duplicate Insert group from More while retaining insertion commands in the palette and shortcuts.
- Fixes semantic keys for visual/focus/typewriter toggle labels and six diagram insertion commands, preventing English labels in the Chinese interface.
- Nightly targets the next patch after stable publication. The existing homepage download list switches stable/Nightly versions and shares system-package/Skill rows; Skill sizes use KB.
- Updates the development Skill's version references, dynamic labels, language discovery and release integration rules. The maintainer explicitly authorized this same-version replacement with full tests and three-platform packaging gates retained.

### Desktop languages

- Simplified Chinese is now a bundled declarative language plugin. Built-in English remains the recovery language; preferences and native menus share validated language resources.
- Short UI text uses stable semantic keys and separate JSON catalogues. The host and SDK share the English source catalogue, while author content, file names and technical identifiers retain their own values.
- Language activation, disabling, removal, missing-message fallback and stale asynchronous refreshes are handled explicitly. A minimal independent recovery interface covers English resource loading failures; native recovery commands always use built-in English.
- **Language catalogues now require `catalogVersion: 2`; extension `apiVersion` remains 1. Legacy text-key catalogues are rejected. Authors must migrate translations against the new reference, validate placeholders and repack; changing the version field alone is insufficient.**

### Extension distribution and development

- Dedicated npm/yarn environments manage extension versions. qwertysay synchronizes additions, updates and removals for individual review in TeXPro. Installed extensions stay disabled; removal preserves plugin data by default and respects environment ownership.
- Existing `.tpp`/`.tpt` distribution through `texpro.package` remains supported. New `texpro.source` packages can supply source directly; self-contained JavaScript, language JSON, snippets and static themes can be validated and synchronized without executing the original node_modules copy.
- Source packages requiring compilation need an explicit build decision. Build dependencies disable lifecycle scripts by default; trusting dependency installation scripts is a separate, default-denied choice. Outputs are tied to source fingerprints, preventing failed or changed sources from reusing stale builds.
- Functional plugins own their language resources and receive the current language on each invocation. Templates, guided builds and shared validation were updated. Companion source versions are SDK 0.5.0, qwertysay 0.6.0 and Simplified Chinese package 2.0.0; npm publication is tracked separately from the app release.
- MCP format queries and package inspection share public validation, describe the new language contract and source-build requirements, and remain read-only.
- Stable and Nightly releases now include a versioned extension-development `.skill` archive, checked against the tested source and its referenced resources.

### Website and documentation

- Esperanto UI, documentation and long-form resources are available through a unified language menu. Language metadata, message JSON and Markdown drive discovery without page or router changes. Missing translations fall back explicitly; builds validate keys and placeholders.
- `/docs` and `/developers` open actual articles directly using a shared reader, navigation and search. Existing `/docs/:slug` links remain stable. Code blocks gain on-demand syntax highlighting.
- The existing homepage download list switches between stable and Nightly releases, and stable releases are grouped by version series. An English root README and expanded extension, language-package and translation guidance were added.

### Delivery and validation

- Nightly keeps the 21:23 Asia/Shanghai schedule with hourly recovery checks. Delayed runs belong to the most recent 21:23 window; a published build suppresses automatic duplicates. Manual same-day rebuilds remain available.
- Stable publishing improves draft lookup and asset completeness checks while preserving retry identity and the post-release website refresh.
- The replacement source passed all 162 regression tests with zero failures, skips or TODOs, plus type checks, application/site builds and documentation checks. Three-platform packaging and final publication are verified by this replacement Actions run.
- The original v0.1.1 passed the complete 159-test regression baseline with zero failures, skipped tests or TODOs, type checks, builds, three-platform packaging and release-package verification. It delivers eight installers and the development Skill. Website language switching, file-only discovery of a fourth language, documentation sections and responsive layouts were also checked.

Installers remain unsigned and unnotarized; local TeX requirements are unchanged. Extension build, installation and activation require separate trust decisions; temporary directories are not sandboxes. GitHub scheduling is not guaranteed to be punctual. Packaging is not installation/runtime acceptance on every OS. Esperanto translations remain independently maintained by their contributor.
