## 先把任务放在合适的地方

实时 TeX 渲染继续是 L0 内部增强，不加模式和开关。补全和上下文信息留在正文；插件安装、修改提案和论文 API 是按需工具。电路、逻辑、化学结构式、手写与模板工作坊需要完整操作空间，共用工作台框架，退出后恢复写作焦点。编译详情并入既有问题面板，版本入口按工程是否使用 Git 选择合适工具。

本次也修正了 macOS 工作台导航与窗口三个系统按钮重叠的问题。共享导航预留 92px，Windows／Linux 使用自己的原生标题栏布局。语言入口只保留一个动作，用目标语言显示「English」或「简体中文」。

## 开放能力，同时抽离边界

插件机制参考 Koishi 的生命周期与服务组织思路，使用自己的 API、包格式和宿主，没有复制 Koishi 运行时或控制台，也不声称插件兼容。新增宿主、SDK、示例和开发 Skill 遵循 MIT；第三方内容保留自己的许可。

API 1 开放命令、补全、检查、转换、悬浮信息、文本预览、导入导出、文献、素材、模板、配置和存储等契约。动态补全与悬浮信息进入编辑器，检查结果进入问题面板，修改提案通过写作端口和单次编辑事务应用。其他提供器使用显式工具，高级提供器仍为实验性；MCP 数据不会自动注册外部 stdio 工具。

命令目录由菜单和命令面板共用。包发现、提供器、写作结果、主题应用、工程检查和工作空间分别抽离，继续保留已有保存、主文件、异步身份和撤销机制。没有为这次开放重写所有历史大文件。

插件使用 `.tpp`、主题使用 `.tpt`，底层为 ZIP，主题包拒绝可执行入口。当前按本地包自行分发，没有公开市场或自动更新。SDK 与脚手架分别拆为独立 npm 包 `@gardenialiu/texpro-extension-sdk` 与 `@gardenialiu/qwertysay`（命令 `qwertysay`），以 Baolin Liu（gardenialiu）名义、MIT 协议维护，提供 TypeScript／JavaScript／主题脚手架、校验与打包。宿主与 CLI 共用同一校验核心；实际 tarball 在仓库外安装后验收 TS 编译、打包和拒绝路径，不依赖 Electron。安装和更新保持停用，重新检查再启用，旧包可以回退；开发目录同样安装经过校验的快照。

## 主题自由度必须伴随信任和恢复

主题可覆盖语义色、字体族、字号、正文宽度、圆角和间距，还可以使用包内 CSS 与图片／字体资源。样式经解析器检查并作用于活动主题，不加载远程资源或安装系统字体，减少动态效果时停用包动画。预览可取消；停用、卸载或切回内置主题后清理包样式。

这不构成安全认证。代码插件是以用户权限运行的 Node 程序，可能访问文件、网络和进程；独立进程用于故障隔离，能力声明不是权限沙箱。主题即使没有 JavaScript，也可能隐藏按钮、遮挡内容或伪装可信提示。风险提示进入安装和启用流程，不能只埋在开发文档里。

不依赖主题按钮的原生视图菜单提供「重置外观并停用扩展」。`--safe-mode` 在执行插件前停用全部扩展并恢复纸面，随后由用户逐项重新检查。字体、图像及插件依赖仍需核对各自许可。

## 实时依赖与验证边界

rtex-ts 精确升级到 0.1.11，保留 Henry Yang 与 realtime-tex 的版权来源和 MIT 声明。宏／环境识别和字体缓存复用来自上游；不把上游性能数据写成 TeXPro 的实测成绩。正式 PDF 仍使用本地 TeX，专业定位和搜索按需准备匹配源文的 PDF。

完整回归要求零失败、零跳过、零 TODO，不能用定向补跑代替整套结果。测试包含真实子进程、包完整性与路径、所有示例处理器、工程过期身份、CodeMirror 撤销与 IME 防护。原生旅程验证实际安装、信任、主题预览和恢复、输入、焦点、专业画布及中英文。发行校验另检查 ASAR 与外部 worker；本机目录包再运行实际插件和 LuaLaTeX 会话。

macOS arm64 是本轮实际原生与目录包验收环境，Windows／Linux 的路径约束和样式分支有自动检查，尚不能称为两个系统均完成原生验收。公开开发契约、双语文档、真实截图及配套开发 Skill 用于下一轮交接，发布与合并状态另以 Git 和远端记录为准。

## SDK 与 qwertysay 发布

2026-11-12，[@gardenialiu/texpro-extension-sdk](https://www.npmjs.com/package/@gardenialiu/texpro-extension-sdk) 与 [@gardenialiu/qwertysay](https://www.npmjs.com/package/@gardenialiu/qwertysay) 的 0.1.0 均以 Baolin Liu（gardenialiu）名义、MIT 协议发布。注册表版本和完整性摘要与发布前的 tarball 一致；发布后从注册表重新安装，验证三类脚手架、实际 TypeScript 编译、校验、归档和拒绝路径。公开的是开发工具，插件仍按本地包自行分发。

```sh
npx --package @gardenialiu/qwertysay@0.1.0 qwertysay init my-plugin --id author.example --author "Your name"
```

npm 发布、任务分支推送、应用合并与安装包发布各有独立状态；开发工具已发布不代表 TeXPro 主分支已合并或新应用版本已上线。
