## 安装与应用

主题包通过[扩展](/docs/extensions)安装和启用，不需要执行 JavaScript；带 CSS 的包需确认样式风险后才能启用。选择主题的「预览」暂时查看效果；关闭扩展面板取消预览，恢复此前已应用主题。「应用主题」保存选择，重新启动后恢复。

主题继承 paper、studio 或 night 基础模式。studio 仍为暗工具栏与亮纸面，不会被当成全暗模式。选择内置主题或执行日夜切换会清除包主题选择。停用、卸载或主题不可用时，界面清除包 token 并回退基础模式。

## 作用范围

主题可以调整工具界面、正文纸面、语法、选区、诊断和焦点等语义色，也可以指定界面／正文／等宽字体、字号、正文宽度、圆角和间距。未提供的颜色继承基础模式。正式 PDF、作者字体及图稿指定颜色保持独立；屏幕配色不会写进文档。

主题可以提供包内 CSS，调整布局、排版和交互状态，并引用随包分发的图片与字体。不会安装系统字体，也不加载远程资源或执行 JavaScript。CSS 通过解析器校验并作用于活动主题；减少动态效果偏好下停用包动画和过渡。颜色为六／八位十六进制，字体为普通字体族列表。字号允许 12–36px、正文宽度 400–1600px、圆角 0–24px，间距单位 2–12px 供主题样式使用。包字号和宽度优先于写作设置；切回内置主题后恢复用户设置。

CSS 清单项为 `stylesheet`，需声明 `theme.styles`。普通规则位于主题作用域内，可用 `:scope` 指向根，支持 media、supports、container、layer、font-face、keyframes。`url` 仅允许相对 CSS 的包内 PNG/JPEG/WebP/GIF、WOFF/WOFF2/TTF/OTF。禁止 @import、远程／data URL、CSS 转义、越界和其他资源加载函数。CSS 源上限 128 KiB、单资源 1 MiB、展开资源每主题 2 MiB、包内生成样式合计 4 MiB；具体契约与示例见开发文档。选择器不是跨版本稳定 API，应用升级后需重新验证。

## 安全与恢复

主题样式有很大自由度，也可能隐藏操作、遮挡内容、伪装可信提示或破坏可访问性。字体与图片也应来自可信来源。校验、作用域和“没有 JavaScript”均不等于安全认证；启用前查看作者、许可证和包内容。代码插件还具有本机文件、网络和进程能力。

界面不可用时，从系统原生「视图」菜单选择「重置外观并停用扩展」，或使用 `--safe-mode` 启动。安全模式在执行插件前停用全部扩展，并恢复内置纸面；恢复后逐项检查再启用。跨平台启动命令见[本地插件包](/docs/extensions)。

仓库的 `examples/extensions/quiet-paper` 是无代码示例，SDK 与 Skill 入口见[插件开发](/docs/extension-development)。请逐项检查正文、菜单、选区、语法、诊断、焦点和窄窗口，并提供准确的真实截图。
