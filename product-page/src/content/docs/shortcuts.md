summary: 下面是应用菜单里真实绑定的快捷键。macOS 用 ⌘，Windows / Linux 把 ⌘ 换成 Ctrl。
---

| 快捷键 | 动作 |
| --- | --- |
| ⌘O | 打开文件夹 |
| ⌘S | 保存当前文件 |
| ⇧⌘W | 关闭工程 |
| ⌘↩ | 编译 |
| ⇧⌘J | Forward Search：从源码跳到 PDF |
| ⌘K | 命令面板 |
| ⌘⌥P | 收起 / 展开 PDF 预览 |
| ⌘\\ | 收起 / 展开侧栏 |
| ⇧⌘M | 切换可视模式 |
| ⇧⌘F | 切换聚焦模式 |
| ⇧⌘T | 切换打字机模式 |
| ⇧⌘L | 切换日间 / 夜间 |

> 在 PDF 上的反向定位不需要快捷键：单击一处就是一次反查。
