## 怎么读

下表只列真实存在的绑定，按作用范围分组。没有写快捷键的动作，就是只能从菜单或命令面板进入。

- macOS：⌘ Command、⌥ Option、⇧ Shift、↩ Return、Esc
- Windows / Linux：⌘ 换成 Ctrl，⌥ 换成 Alt，其余不变
- 「当前文件」指编辑器获得焦点时的行为；焦点在 PDF 或输入框里时，部分组合键会落到别处

## 文件与工程

| 快捷键 | 动作 |
| --- | --- |
| ⌘O | 打开文件夹作为工程 |
| ⌘S | 保存当前文件 |
| ⇧⌘W | 关闭工程，回到欢迎页 |
| ⌘K | 打开命令面板 |

命令面板里能搜到所有菜单动作，包括没有快捷键的那些；它也是确认某个功能是否存在的最快方式。

## 编译、PDF 与定位

| 快捷键 | 动作 |
| --- | --- |
| ⌘↩ | 编译工程 |
| ⇧⌘J | Forward Search：从源码跳到 PDF 对应位置 |
| ⌘-click | 在 PDF 文本层上按住 ⌘ 单击，反查源码行 |
| ⌥⌘P | 收起 / 展开 PDF 预览 |
| ⌘F | 在当前文件内查找 |
| Enter / ⇧Enter | 查找栏内跳到下一个 / 上一个匹配 |
| Esc | 关闭查找栏或悬浮层 |

取消编译没有默认快捷键，只能在 `构建 → 取消编译` 里点。它终止的是整个编译进程组，不只是 latexmk 本身。

> 反向定位不要求先按 Forward Search：在 PDF 上直接 ⌘ 单击就是一次反查。

## 界面与视图

| 快捷键 | 动作 |
| --- | --- |
| ⌘\\ | 收起 / 展开左侧栏 |
| ⇧⌘M | 切换可视模式 |
| ⇧⌘F | 切换专注模式 |
| ⇧⌘T | 切换打字机模式 |
| ⇧⌘L | 切换日间 / 夜间主题 |
| ⇧⌘0 | 进入零界面模式 |
| Esc | 退出零界面模式 |
| ⌘0 | 重置界面缩放 |

零界面模式会隐藏大部分界面元素，只留下正文与一个退出按钮。它不是全屏，按 Esc 或点按钮即可回来。

## 写作模式

| 快捷键 | 动作 |
| --- | --- |
| ⌘⌥← | 回到上一个写作位置 |
| Esc | 离开当前可视块，回到源码编辑位置 |
| ⌥↩ | 同上，用于 Esc 被别处占用时 |
| ⌘⌥P | 切换 PDF 预览（写作时也生效） |

「回到上一个写作位置」用的是一段会话内的位置栈：大纲、搜索、SyncTeX、可视块跳转都会入栈，按一次回到跳转前的文件、光标与滚动位置。栈最多保留 80 个位置。

> 可视模式下的公式、表格、图片都是可编辑块；Esc 退出的只是这一块，不会关闭整个可视模式。

## 编辑器

| 快捷键 | 动作 |
| --- | --- |
| ⌘B | 用 `\textbf{}` 包住选区或光标 |
| ⌘I | 用 `\textit{}` 包住选区或光标 |
| F2 | 重命名标签，并同步工程内的引用 |
| ⌥F12 | 查看光标处引用 / 标签的源码预览 |
| Tab | 补全弹窗打开时接受候选，否则缩进两格 |
| ⌘⇧V | 纯文本粘贴 |
| ⌘Z | 撤销；上一步是跨文件标签重命名时整体回退 |
| ⇧⌘Z | 重做 |
| ⌘Y | 重做（Windows 习惯） |
| ⌥⇧↑ / ⌥⇧↓ | 上移 / 下移当前内容块 |

纯文本粘贴的窗口很短：按下 ⌘⇧V 后 1.5 秒内的下一次粘贴按纯文本处理，不会触发富文本或图片粘贴。要反复粘贴纯文本，每次都要重新按。

> 编辑器里的撤销优先处理「标签重命名」这类跨文件操作；没有可回退的重命名时，才交给编辑器自身的撤销栈。

## 插入与工具

| 快捷键 | 动作 |
| --- | --- |
| ⇧⌘E | 打开公式编辑器 |

其它插入器（表格、图片、TikZ、电路、乐谱等）都没有全局快捷键，从 `插入` 菜单或命令面板进入。可视模式下直接用工具栏更快。

## 最常用的几个

- ⌘K：忘了某个功能在哪，先开命令面板
- ⌘↩：编译；配合 PDF 面板看结果
- ⇧⌘J：写完一段，跳过去核对排版
- ⌘-click：PDF 上看到问题，点回源码
- ⇧⌘0：需要连续写作时，清掉干扰

## 冲突与例外

- ⌘0 是重置缩放，⇧⌘0 才是零界面模式；两者不冲突，但很容易按错
- ⌘Z 在输入框里的行为由系统决定，编辑器里才走工程历史
- ⌘F 只作用于当前编辑器；PDF 里的搜索在 PDF 面板自己的搜索框
- Windows / Linux 上，⌘ 对应的 Ctrl 可能与系统或输入法快捷键冲突；冲突时以应用内菜单显示的组合为准
- 某些键盘布局下 `⌘\\` 依赖物理反斜杠键位；如果按不出来，用命令面板搜「切换侧栏」

> 快捷键不会因为自定义设置而改变。想确认某个动作的绑定，最可靠的地方是菜单项右侧的提示。

## 占位符与修订备忘

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 插入正文占位符 | `⌘⇧H` | `Ctrl+Shift+H` |
| 当前文件下一个／上一个占位符 | `F4` / `⇧F4` | `F4` / `Shift+F4` |
| 留一条修订备忘 | `⌘⇧N` | `Ctrl+Shift+N` |
| 打开修订备忘清单 | `⌘⇧U` | `Ctrl+Shift+U` |
| 应用主文件 CTeX 写作排版 | `⌘⌥⇧C` | `Ctrl+Alt+Shift+C` |

以上操作也可以在命令面板找到。详见[占位符与修订备忘](/docs/writing-aids)和[CTeX 中文写作排版](/docs/ctex-typography)。
