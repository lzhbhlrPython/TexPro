## 安装与启用

从命令面板打开「扩展」，选择「安装插件包…」，加载作者提供的 `.tpp` 插件包或 `.tpt` 主题包。检查名称、作者、版本、许可证、能力和摘要，再选择「安装并保持停用」。包需要 API 1 清单和 LICENSE。

数据包可提供补全、片段、模板和主题。代码包需要勾选信任声明后启用；它们是以当前用户权限运行的 Node 扩展，独立进程用于故障隔离，不是安全沙箱。仅启用你信任的代码。没有公开市场，不会自动下载或更新插件。

## 使用能力

启用的命令进入既有命令面板与工具菜单，静态和动态补全进入正文编辑器。检查器可将结果放入问题面板；转换工具展示修改提案，接受后一次应用，也可一次撤销。文档、工程或扩展状态改变后，不接受过期结果。

插件可以提供按需工具和独立工作台、项目模板、纯文本预览、导入工程提案、导出和文献／素材文本结果。高级提供器仍为实验性；MCP 数据提供器不会自动开放给外部 MCP 客户端。能力接入范围见[插件开发](/docs/extension-development)。

## 更新与恢复

重新安装同一 id 的包完成手动更新。更新后保持停用，重新检查再启用；需要时选择「恢复上一版本」。卸载保留插件本地存储，原始分发文件和作者文档不受影响。

启用失败、进程崩溃和超时会显示错误并停用代码扩展；禁用后不再贡献命令、补全、诊断或主题。重新启用可以重试。若包不兼容 API、内容改变或归档损坏，安装会拒绝。

## 开发模式与主题

「加载开发目录…」安装目录的已校验快照。修改后选择「从目录重新加载」，再检查并启用；不会直接热执行尚未检查的目录修改。宿主不运行安装脚本，不安装 npm 依赖，不加载原生二进制。

主题包的预览、取消、应用与内置主题恢复见[主题包](/docs/themes)。扩展面板、修改提案和专业画布预览来自真实应用；它们的实现和验证说明见开发文档与博客。

## 安全与独立恢复

代码插件可能以你的用户权限读取文件、访问网络、启动进程或接触用户可访问的凭据。能力清单与独立进程不构成恶意代码沙箱。主题无需代码也可能遮挡按钮、伪装界面或损害可读性。只启用可信作者和已检查的包；SHA-256 不是作者签名。

界面被主题破坏时，使用系统原生「视图 → 重置外观并停用扩展」。也可加 `--safe-mode` 启动，在执行插件前停用所有扩展并恢复纸面。macOS：`open -a TeXPro --args --safe-mode`；Windows：`TeXPro.exe --safe-mode`；Linux：可执行文件或 AppImage 加同一参数。停用会保存，之后逐项重新检查并启用。

分发扩展名为 `.tpp`（插件）与 `.tpt`（主题），底层均为 ZIP 归档。`.tpt` 只接受主题配置、CSS 与资源，不接受可执行入口、动作或其他插件贡献；将代码包改名为 `.tpt` 会拒绝，扩展名不代表安全认证。

## 主题开发源码与安装包

开发源码可以是 CSS、SCSS、Sass、Less、Stylus、构建时 CSS-in-JS 或 Thematic CSS（`.tcss`）。新编译能力属于未发布源码，操作见[扩展开发](/docs/extension-development)。所有主题最终是静态 CSS 与资源的 `.tpt`；插件是 `.tpp`，不能把源码后缀或 `.zip` 当作安装后缀。主题没有 JavaScript 也可能隐藏控件或伪装界面，仍需确认可信来源。
