内容始终是同一份 `.tex`。可视层改变「怎么显示」，写作模式改变「显示多少」，主题改变「用什么颜色」。三者都只作用于界面，不改源码，也不参与编译。

## 可视模式

默认开启，`⇧⌘M` 或 「更多 → 视图 → 切换到源码模式／切换到视觉模式」 切换。开启时编辑器把标题、公式、表格、图片、代码块与引用环境渲染成接近排版的组件，语法噪音被收起。

- 点击任何一个渲染结果，光标落到它对应的源码位置，该对象随即展开为源码，可以直接改。
- 光标或选区进入的块会暂时退回源码；移开后重新渲染。
- 导言区折叠成一张卡片，显示文档类、宏包数量与被隐藏的行数，点展开展开。
- 链接在正文里以普通文字显示；按住 `⌘`（Windows / Linux 为 `Ctrl`）点击才在系统浏览器打开。

可视层是语义组件，不是排版引擎：断行、浮动体位置、字体度量一律以 PDF 为准。要判断最终效果，看 PDF，不看编辑器。

## 专注、打字机与零界面

| 模式 | 行为 | 开关 |
| --- | --- | --- |
| 专注模式 | 当前段落之外全部淡出；隐藏侧栏、PDF 与格式栏，正文单列，最大宽度取阅读宽度与 720 px 的较小值 | `⇧⌘F` |
| 打字机滚动 | 选区变化后把光标居中，视口随写随滚 | `⇧⌘T` |
| 零界面模式 | 隐藏标题栏、侧栏、PDF、状态栏、问题面板与格式栏，正文最大 820 px，右上角留一个「退出专注」按钮 | `⌘⇧0`，`Esc` 退出 |

专注模式按「连续非空行块」判断段落：段落之间空一行，才会被当成两段。打字机模式在选区变化 20 毫秒后把光标滚到视口中央，编辑器失去焦点时不动作。

三种模式可以叠加。专注加打字机适合长段写作；零界面适合投影、录屏或纯粹不想看见工具栏的时候。

## 主题

| 主题 | 观感 |
| --- | --- |
| 纸面 | 默认。暖白纸面、深色文字，工具栏收进右上「更多」 |
| 夜间 | 深色界面，夜间写作 |
| 工作室 | 深色侧栏配浅色编辑区 |

`⇧⌘L` 只在纸面与夜间之间切换：当前是工作室时按一次会回到纸面。三套主题在命令面板里各有独立命令（主题：纸面、主题：夜间、主题：工作室），比循环切换更直接。

主题只改界面 CSS 变量。它不影响源码、不影响 PDF、不影响导出；换主题不会让文档「重新排版」。

## 排版参数

| 参数 | 范围 | 默认 |
| --- | --- | --- |
| 字号 | 13 到 22 px | 17 px |
| 阅读宽度 | 620 到 980 px | 760 px |

阅读宽度同时也是专注模式的宽度上限，两者取小。参数存在本机设置里，按工程无关，换工程不重置。

## 输入辅助

Markdown 输入快捷语法只在你键入、且位于正文时生效；导言区、注释、数学、verbatim 与命令参数里保持原样。

- 行首 `# ` 到 `###### ` 换成 `\section` 到 `\subparagraph`。
- 行首 `-`、`+`、`*` 换成 itemize 骨架，`1.` 换成 enumerate，`>` 换成 quote。
- 行尾的 `**粗**`、`*斜*` 与反引号包住的代码换成 `\textbf`、`\emph`、`\texttt`。
- 撤销会还原你打的原语法，而不是逐字撤销转换结果。

智能粘贴在粘贴时判断来源：剪贴板里已经有 TeX 命令就原样贴；网页 HTML 转成粗体、斜体、等宽、链接与列表，遇到合并单元格则退回纯文本；列数一致的 TSV 转成 tabular；Markdown 转成标题、列表、引用、代码块与表格。`⌘⇧V` 始终按纯文本粘贴。

拼写检查只检查拉丁字母单词，命令、数学、verbatim、URL 与邮箱先被掩掉；它不判断中文用词。`显示行号` 控制行号 gutter。

状态栏中间给三样东西：Ln/Col、选中字符数、`{n} 词`。词数先去掉注释、环境标记与命令，西文按空白切词，中文按字计数，所以中英混排的稿子会看到一个偏大的数字。

## 界面语言与命令面板

设置里可以切中英文界面，菜单、命令面板与提示同步换语言。`⌘K` 里搜主题、模式、面板名都能直接执行，比记快捷键稳；命令面板同时是发现入口，很多工作室面板只在里面出现。

## 常见坑

- 专注模式按连续非空行块分段：段落之间不空行，就会被当成同一段。
- 零界面不是全屏：它只隐藏界面元素，PDF 与编译照常运行，`Esc` 或右上角按钮退出。
- 打字机模式依赖编辑器焦点，点到侧栏时不会滚动。
- 数学环境里打 `*` 不会被换成 emph，这是故意的；离开数学后才会转换。
- 关闭可视模式后，「点击渲染对象回到源码」的行为也随之消失。
- 工作室不是默认主题；新装或重置设置后是纸面。
- 专注模式会收起 PDF 面板，边写边核对版式时先退出专注，再用 `⌘⌥P` 单独开 PDF。
- 词数不是投稿口径：中文按字计数，导言区里的标题与作者也算进去，只能看趋势。

## 多文件工程的原位预览

从文件树打开章节文件后，可视层会读取工程主文件和导言区中静态引用的样式文件；不需要一直打开主文件。主文件或样式文件尚未保存的编辑也会参与预览，组合输入期间不会替换正在输入的内容。

图片路径与常规编译一致，以工程工作目录为基准，并识别字面量 `\graphicspath`。例如工程根目录有 `images/实验.png`，即使当前文件位于 `sections/chapter.tex`，仍可写：

```tex
\includegraphics{images/实验.png}
```

可省略常见图片扩展名；PDF 图片由 PDF.js 显示第一页。通过素材入口插入图片也采用工程工作目录，不自动改写已有图片命令。

简单必选参数宏可以参与公式显示，简单文字样式包装也可继承，例如导言区的 `\newcommand{\unit}[1]{\,\mathrm{#1}}`。点击公式或图片可回到对应源码继续写作，保留焦点和撤销。表格中的公式使用同一套宏上下文。

快速投影无法处理的宏段落、自定义环境、复杂表格和公式会交给工程自己的本地 TeX。字面量章节引用原位展开为连续文流，点击内容进入实际子文件编辑。普通原生文字在可靠时使用编辑器字体与行距，几何结构保留真实图形；整页 PDF 留在预览区。普通文字、简单公式与表格仍沿用即时编辑路径。

使用前安装工程所需的 TeX 工具链、字体和宏包，选择正确主文件，在设置中开启「视觉模式」和「自动编译」，并将「编译策略」设为非「仅手动」。暂停输入后等待真实排版；长工程首次生成需要实际编译时间。原生预览使用含未保存缓冲区的临时工程，不主动保存作者文件；已有自动保存与正式自动编译的保存行为不变。退出工具后继续原处写作，无需新增工作空间或引擎模式。

点击原生块会展开对应 TeX，Enter／Space 也可进入。原位源码与「源码」状态继续提供语法高亮、补全和诊断；它们与所见即所得分别保留。修改和撤销通过编辑器完成，过期结果不会替换新输入。

如果问题列表提示原生排版不可用或映射不完整，保留可编辑源码。先核对原工程能否正常编译，补齐字体／宏包、修复 TeX 错误，再修改或重新打开文件重试；导言区依赖不完整时检查引用并重新打开工程。超大快照、超长单块或缺少 SyncTeX 的内容可能保持源码；原生区域不保证每次按键都立即刷新。任意 HTML 不会在 `.tex` 中作为网页执行。最终字体、浮动位置与分页仍看编译 PDF；XeLaTeX 工程不会因此切换引擎。

## 常见几何与绘图宏包

沿用工程的宏包声明与本地 TeX 环境，在正文输入原有代码即可，图形点击后展开源码。无需进入独立工作台；缺包时在本机 TeX 发行版中安装，不会修改项目来偷偷替换宏包。

| 内容 | 宏包／语法 |
| --- | --- |
| 欧氏几何、三角形、圆与辅助线 | TikZ、tkz-euclide；保留工程的坐标、相交与角度库 |
| 三维坐标、空间几何 | tikz-3dplot、PGFPlots 的 addplot3；Lua graphdrawing 使用 LuaLaTeX |
| 平面／三维函数图、坐标图组 | PGFPlots 的 axis、semilogxaxis、semilogyaxis、loglogaxis、polaraxis、groupplot |
| 基础线图 | picture、pict2e |
| 树、交换图与关系图 | Forest、qtree、tikz-qtree、tikz-cd、Xy-pic |
| 证明树 | bussproofs、ebproof、logicproof |
| 电路、量子线路与化学 | Circuitikz、Quantikz、QCircuit、Chemfig |
| 集合图、流程、时间结构 | venndiagram、smartdiagram、pgfgantt |
| PostScript 几何与三维图 | PSTricks、pst-eucl、pst-3dplot；原位图稿使用 XeLaTeX 与其驱动依赖 |
| 物理相互作用图 | tikz-feynman；自动布局可能另需 LuaLaTeX |

例如先在主文件导言区加载 `tkz-euclide`，再在正文输入：

```tex
\begin{tikzpicture}
  \tkzDefPoints{0/0/A,3/0/B,1/2/C}
  \tkzDrawPolygon(A,B,C)
  \tkzLabelPoints(A,B,C)
\end{tikzpicture}
```

tikz-3dplot 先加载 TikZ；qtree 与 tikz-qtree、bussproofs 与 ebproof 按工程实际声明选择，不混装。主文件的宏、库和样式会传入图稿编译。图稿失败时查看原位错误／日志并检查主工程能否编译；复杂或未完成语法保持源码。以上列出已覆盖的语法家族，不承诺每种版本、布局选项或可视化拖拽编辑均支持。

tkz-elements、luadraw 等 Lua 宏包要求相应本地版本与 LuaLaTeX，本轮没有完成这两者的真实编译验收。Asymptote、MetaPost、外部生成文件和需要 shell-escape 的流程不自动执行；继续使用原工程已配置的构建动作和正式 PDF。

## 手写内容进入工作室

手写电路、几何与完整 MusiXTeX 谱段无需经过工作室生成，也不需要补元数据。图形预览中的「工作室」或光标位于块内时的对应工作台命令，打开原始源码；乐谱的「工作室」打开「乐谱工作室」。源码保留高亮与撤销，暂停输入后更新真实排版预览。取消保留正文原文，「应用修改」替换原块并可在正文一次撤销。

中性线条与谱线随明暗主题；作者指定颜色保留，不整体反相。复杂源码无法无损还原为可拖拽节点／音符时，继续使用源码与实时预览。电路工作台提供「源码与实时预览」；修改偏离生成模型后不直接切回旧模型覆盖。图表工具的源码面板可编辑，手写源码优先于数据生成结果。


### 同一工作室的两种模式

点击对象的「工作室」进入对应工具，再用「源码编辑」与「可视编辑」切换；没有独立的源码工作室。两种模式共用草稿与实时预览。可视控件可无损修改字面量坐标、部分 MusiXTeX 音高／拍号／调号和简单 PGFPlots 函数表达式，源码同步显示结果。源码修改后重新识别控件；未知语法保留，只说明当前不能可视编辑的部分，不恢复旧模型覆盖手写内容。取消不改正文，「应用修改」才回写，正文可撤销。
