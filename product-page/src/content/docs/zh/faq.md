## 需要联网吗

不需要。TeXPro 是桌面应用，打开工程、编辑、编译、看 PDF 全在本机完成。唯一会联网的地方是你主动发起的那几个：Git 远程、Overleaf、arXiv 上传、可选 AI 助手，以及页面上展示版本号时的 GitHub Releases 查询。

## 必须自己装 TeX 吗

是。TeXPro 不打包 TeX 发行版，它调用本机已有的 `latexmk` 与引擎。macOS 装 MacTeX 或 BasicTeX，Windows 与 Linux 装 TeX Live，中文项目建议包含 `ctex`。

## 支持哪些平台

macOS 13 及以上（Universal，Apple 芯片与 Intel 通用）、Windows 10 及以上 x64、Linux x64（AppImage，另有 deb / rpm）。目前主要在 macOS 上做界面回归，另外两个平台的构建由同一份 nightly 流程产出。

## 提示找不到 pdflatex

两种常见原因：

- 发行版没装，或者装了但没进 `PATH`；
- 从图形界面启动应用时拿不到登录 shell 的环境变量（macOS 上尤其常见）。

先在终端里跑 `which latexmk` 确认路径，再在 TeXPro 的编译设置里指定可执行文件；或从终端启动应用，让它继承完整环境。

## 中文编译乱码或报字体缺失

把引擎切到 XeLaTeX 或 LuaLaTeX，并在导言区使用 `ctex` 宏包。字体是否真的被找到，可以用字体覆盖面板检查；缺字体时编译日志里会写明具体字体名。

## `.texpro/` 要不要提交到仓库

由你决定。它保存工程配置、内容快照与回收站，属于本机工作状态；多数人会和 `.gitignore` 一起处理，团队共享工程时也建议忽略，让每个人各自保留历史。

## 能替代 Overleaf 吗

定位不同。TeXPro 面向「一个人把一篇稿子写完」，工程文件在你自己的磁盘上；Overleaf 是在线协作与云端编译。两者可以通过 Git 往返：Overleaf 支持从 Git 克隆，TeXPro 也有 Git 面板。

## 多人协作是怎么做的

局域网临时房间：一方开启协作后，同一网络下的人用房间码加入，编辑内容通过本机 WebSocket 同步。它不是云同步，没有账号体系，也不做长期存档。

## AI 会把我的稿子传出去吗

默认不会。AI 助手是可选的：只有你配置了服务与密钥，并在选中文本后主动发起请求，选中的内容才会发送出去。不配置就一直不联网，其它功能不受影响。

## 编译很慢怎么办

先确认是不是每次都全量构建：观察底部状态栏的耗时。常见加速手段是用 `latexmk` 的增量构建、把图片转成 PDF 或降低分辨率、以及把长文档拆成子文件——`\include` 的章节可以只编译当前部分。

## 卸载会删掉我的稿子吗

不会。稿子在你选择的工程目录里，卸载应用不会碰它。应用自己的配置、历史与模板在用户数据目录，需要彻底清理时手动删除即可。

## 数据和设置分别存在哪

- 工程相关：工程目录 + 其中的 `.texpro/`；
- 应用相关：系统用户数据目录下的 TeXPro 文件夹（设置、最近打开、用户模板、MCP 配置）。

AI 密钥单独存成该目录下的 `secrets.json`，由系统安全存储加密、权限 `0600`；系统不提供加密能力时保存会直接失败，不会退化成明文。

## 快捷键能改吗

应用菜单里的快捷键目前是固定的，可以在「快捷键」一页查到完整对照；编辑器内部另有一套 CodeMirror 键位，跟随编辑器习惯。命令面板提供不依赖快捷键的入口。
