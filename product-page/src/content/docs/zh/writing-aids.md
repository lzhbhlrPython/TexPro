## 占位符：先继续写

配图、表格、引用或数据暂时没有准备好时，在正文按 `⌘⇧H`（Windows / Linux 为 `Ctrl+Shift+H`）。编辑器插入占位符并选中说明，直接写下待补内容。继续输入正文即可，无需打开工作间。

左侧「占位符」列表可以选择正文、配图、表格、引用、数据五种类型。点击条目会选中源文件中对应的完整命令，输入真实内容即可替换。`F4` / `Shift+F4` 在当前文件的占位符间循环。命令面板 `⌘K` 同样能找到这些操作。

```tex
\texproplaceholder[figure]{补一张实验装置示意图}
\texproplaceholder[data]{核对最终样本量}
```

插入命令会把所需的兼容宏放进工程的实际主文件，正文仍留在当前子文件；两处修改作为一组撤销。已有自定义同名宏时保留作者定义。普通 LaTeX 发行版即可编译，无需新增外部程序。

## 草稿与正式提交

配图、表格占位符在草稿 PDF 中保留框与说明，其他类型显示行内框。它们不会自动生成真实图片、文献或数据。编译问题面板会给出待补项的位置；源文件导出也会提示。创建 arXiv 投稿包前必须清空工程中的占位符，避免把待办当作成稿提交。

占位符列表包含工程内的 `.tex` / `.ltx` 文件；隐藏目录、构建目录和符号链接不参与扫描。未被主文件包含的草稿也会出现在工程清单中，应在正式打包前处理或移出工程。手工输入命令时，需要自己保留主文件里的宏定义；推荐使用插入操作自动安装支持。

## 修订备忘：下次从这里接着改

在当前段落按 `⌘⇧N` 留下备忘，直接在源文件注释中输入内容；按 `⌘⇧U` 打开修订备忘清单。备忘记录在普通注释里，不进入 PDF，也不依赖应用数据库。

```tex
这一段先保留现有论证。
% MEMO: 下次核对第三段和图 2 的结论是否一致
% MEMO-DONE: 已补充实验条件
```

重新打开文件时，编辑器上方会提示该文件最后一条未完成的备忘。点击提示回到相邻段落；可以标为完成或关闭本次提示。关闭提示不删除注释，完成后仍可在清单里重新打开。原有 `% TODO:`、`% FIXME:`、`% NOTE:` 和 `% DONE:` 继续兼容。

## MCP 协作

`texpro_writing_aids` 返回已保存文件中的占位符、备忘、UTF-16 偏移与 SHA-256。`texpro_edit_writing_aid` 支持插入、替换、添加备忘和完成／重开备忘。修改必须提交刚读取的文件哈希；插入占位符还需主文件哈希，防止覆盖外部改动。

MCP 操作直接读写磁盘，无法读取编辑器里尚未保存的缓冲区。交给外部客户端处理前先保存，返回编辑器后检查外部变更。不要用过期的偏移重复请求。
