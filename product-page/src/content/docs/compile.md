## 三个引擎

| 引擎 | 特点 |
| --- | --- |
| pdflatex | 最快，老宏包兼容性最好 |
| xelatex | 默认推荐，直接使用系统字体与中文排版 |
| lualatex | 现代引擎，Unicode 与 Lua 宏包 |

引擎按工程记忆，切换不需要改导言区。latexmk 会自己处理需要跑几遍的问题（交叉引用、参考文献）。

## 自动编译的三种时机

| 时机 | 行为 |
| --- | --- |
| 手动 | 只有按下 ⌘↩ 才编译，其余时间完全不动 |
| 停顿后 | 停止输入一小会儿后自动编译，适合边写边看 |
| 预览打开时 | 只在 PDF 面板可见时编译，省电也省机器 |

## 诊断

编译错误、警告与 overfull box 都会进底部「问题」面板，点一条跳到对应源码行。状态栏右侧常驻耗时与警告数，不用另开终端看日志。

> 编译在后台进行，不阻塞输入。切换工程或重新编译时，上一轮迟到的结果会被丢弃，不会覆盖当前文件。
