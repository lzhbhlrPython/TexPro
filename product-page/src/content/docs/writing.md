内容始终是同一份 `.tex`。可视层改变「怎么显示」，写作模式改变「显示多少」，主题改变「用什么颜色」。三者都只作用于界面，不改源码，也不参与编译。

## 可视模式

默认开启，`⇧⌘M` 或 `View → Toggle Visual Mode` 切换。开启时编辑器把标题、公式、表格、图片、代码块与引用环境渲染成接近排版的组件，语法噪音被收起。

- 点击任何一个渲染结果，光标落到它对应的源码位置，该对象随即展开为源码，可以直接改。
- 光标或选区进入的块会暂时退回源码；移开后重新渲染。
- 导言区折叠成一张卡片，显示文档类、宏包数量与被隐藏的行数，点 Reveal 展开。
- 链接在正文里以普通文字显示；按住 `⌘`（Windows / Linux 为 `Ctrl`）点击才在系统浏览器打开。

可视层是语义组件，不是排版引擎：断行、浮动体位置、字体度量一律以 PDF 为准。要判断最终效果，看 PDF，不看编辑器。

## 专注、打字机与零界面

| 模式 | 行为 | 开关 |
| --- | --- | --- |
| Focus mode | 当前段落之外全部淡出；隐藏侧栏、PDF 与格式栏，正文单列，最大宽度取阅读宽度与 720 px 的较小值 | `⇧⌘F` |
| Typewriter scrolling | 选区变化后把光标居中，视口随写随滚 | `⇧⌘T` |
| Zero interface | 隐藏标题栏、侧栏、PDF、状态栏、问题面板与格式栏，正文最大 820 px，右上角留一个 Exit focus 按钮 | `⌘⇧0`，`Esc` 退出 |

专注模式按「连续非空行块」判断段落：段落之间空一行，才会被当成两段。打字机模式在选区变化 20 毫秒后把光标滚到视口中央，编辑器失去焦点时不动作。

三种模式可以叠加。专注加打字机适合长段写作；零界面适合投影、录屏或纯粹不想看见工具栏的时候。

## 主题

| 主题 | 观感 |
| --- | --- |
| Paper | 默认。暖白纸面、深色文字，工具栏收进右上「更多」 |
| Night | 深色界面，夜间写作 |
| Studio | 深色侧栏配浅色编辑区 |

`⇧⌘L` 只在 Paper 与 Night 之间切换：当前是 Studio 时按一次会回到 Paper。三套主题在命令面板里各有独立命令（Theme: Paper、Theme: Night、Theme: Studio），比循环切换更直接。

主题只改界面 CSS 变量。它不影响源码、不影响 PDF、不影响导出；换主题不会让文档「重新排版」。

## 排版参数

| 参数 | 范围 | 默认 |
| --- | --- | --- |
| 字号 | 13 到 22 px | 17 px |
| 阅读宽度 | 620 到 980 px | 760 px |

阅读宽度同时也是专注模式的宽度上限，两者取小。参数存在本机设置里，按工程无关，换工程不重置。

## 输入辅助

Markdown input shortcuts 只在你键入、且位于正文时生效；导言区、注释、数学、verbatim 与命令参数里保持原样。

- 行首 `# ` 到 `###### ` 换成 `\section` 到 `\subparagraph`。
- 行首 `-`、`+`、`*` 换成 itemize 骨架，`1.` 换成 enumerate，`>` 换成 quote。
- 行尾的 `**粗**`、`*斜*` 与反引号包住的代码换成 `\textbf`、`\emph`、`\texttt`。
- 撤销会还原你打的原语法，而不是逐字撤销转换结果。

Smart paste 在粘贴时判断来源：剪贴板里已经有 TeX 命令就原样贴；网页 HTML 转成粗体、斜体、等宽、链接与列表，遇到合并单元格则退回纯文本；列数一致的 TSV 转成 tabular；Markdown 转成标题、列表、引用、代码块与表格。`⌘⇧V` 始终按纯文本粘贴。

拼写检查只检查拉丁字母单词，命令、数学、verbatim、URL 与邮箱先被掩掉；它不判断中文用词。`Show line numbers` 控制行号 gutter。

状态栏中间给三样东西：Ln/Col、选中字符数、`n words`。词数先去掉注释、环境标记与命令，西文按空白切词，中文按字计数，所以中英混排的稿子会看到一个偏大的数字。

## 界面语言与命令面板

设置里可以切中英文界面，菜单、命令面板与提示同步换语言。`⌘K` 里搜主题、模式、面板名都能直接执行，比记快捷键稳；命令面板同时是发现入口，很多工作室面板只在里面出现。

## 常见坑

- 专注模式按连续非空行块分段：段落之间不空行，就会被当成同一段。
- 零界面不是全屏：它只隐藏界面元素，PDF 与编译照常运行，`Esc` 或右上角按钮退出。
- 打字机模式依赖编辑器焦点，点到侧栏时不会滚动。
- 数学环境里打 `*` 不会被换成 emph，这是故意的；离开数学后才会转换。
- 关闭可视模式后，「点击渲染对象回到源码」的行为也随之消失。
- Studio 不是默认主题；新装或重置设置后是 Paper。
- 专注模式会收起 PDF 面板，边写边核对版式时先退出专注，再用 `⌘⌥P` 单独开 PDF。
- 词数不是投稿口径：中文按字计数，导言区里的标题与作者也算进去，只能看趋势。
