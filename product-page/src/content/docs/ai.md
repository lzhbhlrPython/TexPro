## 默认关闭

TeXPro 不附带模型，也不替你做任何自动补全式的改写。AI 是一个需要你自己接上的可选功能：不配置时，应用不会向 AI 服务发起任何请求。

配置在 `设置 → 可选 AI`：

- 打开「启用 AI 助手」开关
- 填入服务地址，默认是 `https://api.openai.com/v1`，末尾不要带 `/chat/completions`
- 填入模型名，默认是 `gpt-4o-mini`
- 填入 API 密钥

密钥不会写进普通设置，也不会进入 `localStorage`。它由主进程通过系统安全存储加密后，存成应用数据目录下的 `secrets.json`；文件权限是 `0600`。如果系统不提供加密能力，保存会失败并给出提示，而不是退化成明文。

## 打开面板

`项目 → AI 助手…`，或在命令面板里搜索 `AI 助手`。

未配置时，面板不会显示任务，只显示一张设置卡片；所有按钮都不可用，也不会出现「试一下」的入口。

## 六种任务

| 任务 | 发送的上下文 | 产出 |
| --- | --- | --- |
| 解释编译错误 | 当前编译错误与诊断行 | 错误解释与最小修改建议 |
| 改写得更清晰 | 光标附近几行 | 更清楚的 LaTeX 段落 |
| 翻译为中文 | 光标附近几行 | 保留命令与公式的中文译文 |
| 翻译为英文 | 光标附近几行 | 保留命令与公式的英文译文 |
| 根据描述生成 LaTeX | 你输入的自然语言描述（默认填入光标附近几行，可替换） | 单个数学表达式，不带 `$` |
| 智能体操作 | 当前选区（没有选区时用默认上下文） | 结构化编辑动作 |

每个任务都带有固定的系统提示：翻译与改写会要求保留全部命令、引用、标签与公式；`智能体操作` 要求只返回 JSON，不返回解释性文字。

## 上下文可以改

面板里的「上下文」是普通文本框，发送前可以增删。默认内容按任务决定：

- 解释错误：取当前编译结果里的错误行
- 智能体操作：取当前选区
- 其它任务：取光标所在行前后约五行

文本框为空时，仍然会发出一个「没有提供上下文。」的占位内容，而不是悄悄取消请求。

> 只有这个文本框里的文字会离开本机。工程目录、其它文件、PDF 都不会被自动打包上传。

## 运行与采纳

点击「运行」后，请求以流式返回，结果逐步出现；「停止」会中断当前请求。

- 普通任务：结果出现在下方文本框，点「插入结果」才会插入到光标处，插入后面板关闭
- 智能体操作：结果被解析成若干张动作卡片，每张写明动作类型与理由，点「应用操作」才执行，执行过会标记为「已应用」

智能体操作只认三种动作：`insert`、`replace-selection`、`replace-document`。模型返回的内容不是合法 JSON、或没有可执行动作时，面板会报错，不会偷偷改文件。

> 没有「接受全部」，也没有自动应用。批量修改请逐条看。

## 请求细节

- 协议：OpenAI 兼容的 Chat Completions，`POST {baseUrl}/chat/completions`
- 鉴权：`Authorization: Bearer <apiKey>`
- 参数：`temperature: 0.2`、`stream: true`，消息只有一条 system 与一条 user
- 失败时会显示状态码与响应片段，例如 `AI request failed (401)`
- 不保留对话历史：每次运行都是独立的一轮，只带当前任务的系统提示与上下文

因此，任何兼容该协议的服务都能用：自建网关、代理、本地推理服务，只要它能流式返回 `choices[0].delta.content`。

## 隐私与边界

- AI 默认关闭，且永远不会自动运行；没有后台预热、没有自动摘要
- 密钥只存在本机；请求从应用直接发往你填的地址，不经过 TeXPro 的中转
- 服务提供方会看到你发送的文本，其日志与留存策略由对方决定
- 模型可能生成无法编译的 LaTeX，也可能改错命令；先编译，再接受
- 需要工程级的读写、编译与检索时，用 MCP，而不是把整个工程贴进对话框

> 换服务或换模型不需要重启：保存设置后，下一次运行就使用新配置。

## 出问题时

| 现象 | 先检查 |
| --- | --- |
| 面板只显示设置卡片 | 开关是否打开、密钥是否非空 |
| `AI request failed (401)` | 密钥是否正确、是否过期 |
| `AI request failed (404)` | 服务地址是否多写或漏写了 `/v1` |
| `AI returned an empty stream` | 服务是否支持流式；换成支持流式的代理再试 |
| 智能体操作报「没有有效动作」 | 模型是否按 JSON 返回；换一个指令遵循更强的模型 |
